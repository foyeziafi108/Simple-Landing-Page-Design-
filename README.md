# 🍽️ Restro - Restaurant Landing Page

A modern restaurant landing page designed using only **HTML** and **CSS**.

## 📌 Project Overview
Restro is a simple and stylish landing page for a restaurant website. It has a dark theme with orange highlights, a navigation menu with icons, a big hero heading, and a round food image. This project is made to practice HTML and CSS layout and design skills.

## ✨ Features
- Dark theme with orange accent color
- Navigation bar with Font Awesome icons (Home, About, Food, Bookings, Services, Contact)
- Big hero heading with a highlighted word
- "Book Table" call-to-action button
- Round food image on the right side
- Dark overlay on the background image
- Clean Noto Sans typography
- Built with pure HTML and CSS (no JavaScript)
